# BaiduPush · Typecho 百度主动推送插件

自动收集全站已发布内容 URL，主动推送给百度普通收录接口，加速新文章被百度收录。

## ✨ 功能

- **全站收集**：自动收集文章 / 独立页面 / 分类 / 标签 / 首页 URL
- **主动推送**：调用百度普通收录推送接口（data.zz.baidu.com），支持批量提交
- **三种模式**：增量（只推新增，推荐）/ 全量 / 单篇（发布/更新即推）
- **定时自动推送**：每天最多自动推送一次（依赖站点访问触发，亦可计划任务 curl 触发）
- **发布即推**：新文章发布、老文章更新后实时推送该条 URL（fire-and-forget 不阻塞）
- **失败重试**：失败 URL 自动记录，可一键重试；配额用尽自动跳过、次日重推
- **自动 Sitemap**：推送成功后自动生成 / 更新 `sitemap.xml`，含文章修改时间
- **robots.txt 管理**：面板内直接编辑保存
- **统计面板**：今日 / 累计推送量、成功率、失败明细、近 7 天推送趋势图、剩余配额预警
- **安全**：Token 不落公开仓库；触发密钥鉴权；面板管理员鉴权；CSV 导出防公式注入

## 📦 安装

1. 将本仓库文件夹（`BaiduPush/`）放入 Typecho 的 `usr/plugins/` 目录，插件名为 `BaiduPush`
2. 后台 **插件** 页启用「BaiduPush」
3. 后台顶栏出现「🔗 百度推送」入口，点击进入面板

## ⚙️ 配置（插件 → 设置）

| 配置项 | 说明 |
| --- | --- |
| 百度推送 Token | 百度站长平台 → 资源提交 → 普通收录 → 推送接口 里的 token |
| 站点地址 | 含协议，末尾不带斜杠，如 `https://example.com` |
| 推送模式 | 增量（推荐）/ 全量 |
| 定时自动推送 | 开启后每天自动推送一次 |
| 触发密钥 | 用于计划任务 curl 触发（可留空，留空时插件用自动生成的内部密钥自触发） |

## 🔧 计划任务触发（可选）

```
curl "https://example.com/usr/plugins/BaiduPush/push.php?key=你的密钥&mode=incremental"
```

`mode` 支持 `incremental` / `full` / `dry`（干跑）/ `single&cid=文章ID`。

## 🧩 兼容性

- Typecho 1.2+ / 1.3（建议 1.3），PHP 7.4+（需 curl 扩展）
- 数据库：SQLite / MySQL 自动适配
